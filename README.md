## 🧠 项目理解

colleague.skill 是一个用于：

- 根据资料生成“AI同事技能”
- 模拟不同风格的 AI 代理
- 结合 persona + work capability 的 agent 框架

简单理解：

> 👉 输入资料 → 生成一个“像某个人一样工作的 AI”


## 💡 使用方式

在 Claude Code 中运行：

```
/create-colleague
```

然后按照提示输入信息即可生成 Skill。
